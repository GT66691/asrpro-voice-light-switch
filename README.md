# ASRPRO 语音关灯（单舵机 · 机械按压）

用 **天问 ASRPRO** 识别“关灯”指令，驱动 **MG90S 舵机左右摆动**，依次压下两个翘板开关的“关”侧，实现语音关灯。

全程使用 5V 低压，舵机只做机械按压，**不接入 220V 市电，也不改墙面开关内部接线**。

---

## 功能

- 唤醒词 **“牢大”** → 命令词 **“关灯”**
- 舵机：左摆压左开关 → 右摆压右开关 → 回中
- 只做“关灯”，开灯仍手动按
- 灯已经关着时，再压一次**不会误开**（下半边已凹进去，压空）
- 一个舵机、一根信号线，电源直接用 ASRPRO 的 5V

## 工作原理

小翘板开关是绕中轴翻的：

- 下半边**凸起** = 灯亮（开）
- 把下半边**压进墙里** = 灯灭（关）

所以舵机只需要在两个位置各压一下：

```
90°（回中） → 70°（压左开关） → 110°（压右开关） → 90°
```

如果某个开关已经是关的状态，它的下半边本来就是凹进去的，舵机压过去只是“压空”，不会把它重新打开。这就是这套方案能自动纠错的原因。

## 硬件清单

| 元件 | 数量 | 说明 |
|---|---|---|
| 天问 ASRPRO 开发板（ASRPRO-2M） | 1 | 语音识别 + 舵机控制 |
| MG90S 舵机 | 1 | 金属齿，扭矩足够压小翘板 |
| 5V/2A USB 电源 | 1 | 给 ASRPRO 供电 |
| 1000µF 电解电容 | 1 | 并在 5V/GND，吸收舵机启动电流 |
| 硅胶/橡皮推头 | 1 | 贴在舵机臂上，软接触、防刮 |
| 支架 / 3M VHB | 1 | 固定舵机，可无损拆除 |
| 杜邦线 | 若干 | 接线 |

> 本方案只用一个舵机，可以直接从 ASRPRO 的 5V 引脚取电。  
> 如果以后加第二个舵机，必须改用**外部 5V 电源并共地**，不要从板子取电。

## 接线

```
ASRPRO
 5V   ── 舵机 红线（VCC）
 GND  ── 舵机 棕线（GND）
 IO13 ── 舵机 橙线（信号）

5V 与 GND 之间并 1000µF 电容（靠近舵机）
```

- 舵机线色以实物标注为准，**电源两根接反会烧舵机**
- 电容长脚（+）接 5V，短脚/白条（−）接 GND
- 下载程序时建议拔掉舵机电源，减少电流冲击

## 机械安装

侧视（左边是墙）：

```
墙面
 │       舵机
 │      ┌────┐
 │      │ ⊙  │  轴水平、平行于面板
 │      └─┬──┘
 │        │ 舵机臂
 │        ▬▬▬  软推头
 │      ┌──────┐
 └──────│ 翘板 │
        └──────┘
```

要点：

- 舵机臂端贴**软硅胶/橡皮**，宽度接近拨片宽度
- 推头对准开关的**下半边**，压到面板齐平就够
- 支架先用 3M 胶或面板螺丝固定，别拧死，方便微调
- 左右两个位置都要能压到开关，且不蹭到边框

## 软件与代码

- 开发环境：**天问Block**（ASRPRO）
- 代码：[src/main.cpp](src/main.cpp)
- 命令词在天问Block 的“命令词”积木里配置，ID 以生成的 `//{ID:...}` 注释为准

### 命令词

| ID | 类型 | 识别词 | 回复词 | 是否驱动舵机 |
|---|---|---|---|---|
| 0 | 唤醒词 | 牢大 | man | 否 |
| 1 | 命令词 | 关灯 | 笑 | **是** |
| 3 | 命令词 | 想你了 | 唱歌 | 否 |
| 4 | 命令词 | 咕咕嘎嘎 | 咕咕嘎嘎 | 否 |

> ID 2 没有使用。代码里的 `case 1` 对应“关灯”；如果你在 天问Block 里重新排列了命令词，请把 `case 1` 改成“关灯”的实际 ID。

### 核心逻辑

```cpp
void ASR_CODE(){
  set_state_enter_wakeup(10000);
  switch (snid) {
   case 1:                           // 关灯（ID 1）
    servo_13.write(LEFT_PRESS_ANGLE);
    delay(PRESS_MS);
    servo_13.write(RIGHT_PRESS_ANGLE);
    delay(PRESS_MS);
    servo_13.write(REST_ANGLE);
    exit_wakeup_deal(0);
    break;
  }
}
```

### 可调参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| `REST_ANGLE` | 90 | 回中 / 静止角度 |
| `LEFT_PRESS_ANGLE` | 70 | 左开关按压角 |
| `RIGHT_PRESS_ANGLE` | 110 | 右开关按压角 |
| `PRESS_MS` | 1000 | 每个位置保持时间（ms） |

调整方法：

| 现象 | 改法 |
|---|---|
| 左开关压不到 | `LEFT_PRESS_ANGLE` 往小调：65 → 60 |
| 右开关压不到 | `RIGHT_PRESS_ANGLE` 往大调：115 → 120 |
| 压过头 / 撞边框 | 往 90 收：75 / 105 |
| 左右方向反了 | 两个角度对调 |
| 回中会蹭到开关 | 调 `REST_ANGLE`，或缩短舵机臂 |

> `//{speak:...}`、`//{ID:...}` 这些注释由天问Block 自动生成，**不要手改**；要改音色、回复词或命令词，请在天问Block 界面里改。

## 使用步骤

1. 按接线图连接舵机和电容
2. 天问Block 中配置唤醒词和命令词
3. 编译下载（下载时拔掉舵机电源）
4. 上电，舵机应回到 90°
5. 说 **“牢大”** 唤醒，再说 **“关灯”**
6. 观察舵机是否依次压左、压右，然后回中

## 常见问题

| 现象 | 排查 |
|---|---|
| 舵机不动 | 信号线是否接 IO13；`attach(13)` 是否执行；电源是否接好 |
| 说“关灯”没反应 | 有没有先说唤醒词；`case` 的 ID 是否和生成注释一致 |
| 舵机抖动 / 板子重启 | 电源带不动；加 1000µF 电容；换 5V/2A 电源 |
| 左/右开关压不到 | 调 `LEFT_PRESS_ANGLE` / `RIGHT_PRESS_ANGLE`；检查推头位置 |
| 压过头 / 开关卡住 | 角度往 90 收；缩短舵机臂；换软推头 |
| 下载报 `error:6` | 串口没连上/没进下载模式；先点下载再复位；关掉占用串口的程序 |

## 安全注意

- 本方案**不接入 220V**，只做机械按压，舵机由 5V 供电
- 不要为了“直接控制灯”去拆改墙面开关内部接线
- 固定舵机用 3M 胶或面板螺丝，退宿时可无损拆除
- 舵机堵转会发热，调试时发现卡住立即断电

## 已知限制

- 只实现“关灯”，不实现语音开灯
- 两个开关必须是**相同方向**（都是下半边为关）；如果其中一个装反，需要调整安装位置
- 一个舵机只能同时/依次控制两个开关，不能单独控制某一个
- 依赖 ASRPRO 的离线识别，环境噪音大时识别率会下降
